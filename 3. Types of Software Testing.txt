There’s a lot going on when you hear about Software Testing, it is not a one-size-fits-all process. There are different types of testing, and each one focuses on a specific aspect of a product. From functional testing to ensure that your app works as expected to non-functional testing that checks things like performance and security,  there’s a test for almost everything. Let me talk about the most common types  of software testing: Functional Testing, Non-Functional Testing, Regression Testing, UAT(User Acceptance Testing), and many more. Each type plays a crucial role in ensuring the product delivers an awesome experience to the user. Functional testing, for example, checks whether the product does what it’s supposed to do. On the other hand, non-functional testing takes into account performance, security, and usability. Knowing which testing type to use, when, and why is a core skill for any QA engineer.
